Les Mondes de Minecraft

1. Le Monde Normal (Overworld)

C’est là où tout commence. Le Monde Normal est l'environnement principal, composé de biomes variés comme les forêts, les déserts, les océans et les montagnes.

On y trouve :

  • Des animaux gentils (poules, vaches, moutons...)
  • Des monstres classiques (zombies, squelettes, creepers... boum)
  • Les ressources de base : bois, pierre, minerai, etc.

C'est un peu la "Terre" de Minecraft. Le terrain de jeu pour construire, explorer et survivre.

2. Le Nether

Aussi appelé l'enfer version cubes. Accessible en construisant un portail en obsidienne.

le Nether est un monde dangereux et hostile :

  • Rempli de lave, de forteresses lugubres et de créatures terrifiantes (Ghasts, Piglins, Blazes…)
  • Parfait pour récupérer des ressources rares comme la Netherite et les bâtons de Blaze (essentiels pour finir le jeu).

Attention : ici, mourir est très rapide (tomber dans la lave, se prendre une boule de ghast...)

Le Nether est un passage obligé pour progresser vers la fin de Minecraft.

3. L'End

Bienvenue dans le monde final. L'End est un endroit :

  • Froid, silencieux, fait d'îles flottantes dans le vide,
  • Peuplé d’Endermen (ne surtout PAS les regarder dans les yeux ),
  • Protégé par le fameux Ender Dragon, boss final du jeu.

Battre l'Ender Dragon permet de "terminer" Minecraft... même si soyons honnêtes, personne n'arrête vraiment de jouer après ça.
